# HIT137 Assignment 3
Image Puzzle Game developed using Python, Tkinter and OpenCV.
Run:
python main.py 

Grid size supported : 3*3, 4*4, 5*5 

Controls:
Left-click: select or swap tile
Right-click: rotate the tiles 90 degrees clockwise
Shift + left-click: flip the tile horizontally
Hint: one small blue show one incorrect tile in swapped image and its correct location on original image
Solve: restore the puzzle
